# 免费数据接入与核心可靠性实施计划

用户决定：软件开源、全免费，内置数据连接方法，由用户自己的本地/服务器环境访问数据源；Tickgrove 不经营共享行情数据服务，不要求订阅 Tickgrove 才能使用功能。

本轮目标是把免费的历史与实时路径做成可实际使用的默认环境，同时修复审查确认的执行和操作问题。数据源不提供的历史/时段应有准确覆盖说明、用户自接源与导入路径，不能用合成报价补成“全面数据”。免费日线长历史、可取得的分钟历史、实时行情及自建缓存分别管理。

| 工作线 | 实施内容 | 验收 |
|---|---|---|
| Rust 数据层 | 免费 Yahoo/Coinbase 路径、共享 HTTP/限流、持久历史缓存与分页、上游连接复用、Alpaca 正确时段/feed/质量合同 | 实际历史/实时请求、多标的多周期、缓存重复请求、分页与数据源边界；故障 fixture |
| React 数据体验 | 切周期加载状态、等待数据后计算指标、旧请求隔离、分页补数与视窗保持、可重试错误、清楚显示来源/范围 | 1m→1H→1m、快速连切、空响应/失败/重试、左移补数、4/6 图、真实源浏览器验收 |
| 自接环境 | 免费源开箱可用、可理解的连接卡片、可选 Alpaca 用户密钥服务器保存/测试、缓存状态与管理 | 不把密钥放浏览器持久存储/报告；权限拒绝、文件权限、无密钥默认路径、连接测试失败反馈 |
| Pine 与提醒 | 拒绝隐式订单降级、成交反馈方向/数量约束、实时提醒持久化、游标与 outbox 原子恢复 | 已复现问题回归、正常订单/部分成交、重启与故障边界；不以拒绝所有交易作为修复 |
| 工作台 | 调网格保留图表、模板替换可撤销、搜索结果对应当前查询、模拟部署定位结果、Pine 缺失依赖直达安装 | 新浏览器定向任务；不触碰公共预览账户进行测试 |
| 集成发布 | 小范围回归→完整现有测试→构建→隔离真实数据验收→备份并更新预览→GitHub | 发布版本和证据一致；记录免费源限制与未验证的外部账户能力 |

根 agent 负责前端数据生命周期、连接配置、集成和验收；三个子 agent 分别实现 Rust 行情、运行时可靠性和工作台交互。共享文件提前分配，Rust 构建串行，主 agent 交叉复核。生产预览在隔离验收后更新，保留数据库、token 和工作区。

本轮不采购数据、不建设项目付费数据网关、不加入 AI 聊天。既有自托管与 CLI/MCP/插件接口继续可用。正式数据源的真实权限和超出免费源范围的历史不会以 mock 通过宣称已完成。
