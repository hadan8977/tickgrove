# Open Composer：修订计划（v2）

## 1. 定位
- **Open Composer** 是一个全新的、独立的开源交易工作台。它不是 hadan8977/open-composer 的新前端，也不是那个仓库 Dashboard 的升级或迁移。
- 那个旧仓库只作为**选择性参考**：只评估非界面能力，合适就借鉴，不合适就换用其他开源方案或重新设计。旧 Dashboard 的页面、导航、组件、状态和接口都不复用。
- 本轮交付一个能独立运行、完成度高、可以交互的前端。不依赖旧项目的部署和服务。
- 体验参考：看盘以 TradingView 的专业度为主，策略构建借鉴 Composer 的可视化方式，工作区借鉴 OpenBB 的模块化。不做管理后台，也不内置 AI 聊天。

## 2. 核心体验（优先打磨，一条完整闭环）
1. **工作区**：支持 1/2/4/6 图布局，面板可以拖拽停靠、调整大小，也可以保存和切换布局。每张图有自己的标的和周期，可以开关“联动组”（同步标的、周期、十字光标）。
2. **行情与自选**：自选分组，有实时跳动的模拟价格。点击标的会切换当前联动组里的所有图表。旁边配有标的详情和简易盘口/成交。
3. **图表**：K 线、成交量、多周期切换。指标可以叠加在主图上，也可以放在副图窗格。绘图工具包括趋势线、水平线、矩形、斐波那契和文字。
4. **Pine 编辑与应用**：编辑器支持高亮、补全和错误提示。可以运行并“添加到图表”，输入参数能生成设置面板。脚本保存在库中，按指标或策略分类。
5. **可视化策略构建器**：Composer 风格的条件/分配块树，用来定义入场、出场、仓位和风控。可以生成 Pine，由用户确认后进入 Pine 编辑器。只承诺单向生成，Pine 反解析为积木块仅针对受支持的子集，无法转换时明确提示。
6. **回测**：可以从 Pine 策略或可视化策略发起回测。报告包含权益曲线、回撤、交易列表和关键指标，交易会标记在图表上。
7. **模拟交易**：支持下单、持仓、委托和成交记录。从回测可以一键“部署到模拟”。

## 3. 执行状态的明确区分（全局一致）
三种状态各有独立的徽标、颜色和文案，显示在顶栏、下单面板和数据源上：
- `演示 DEMO`：示例数据和本地模拟。本轮全部内容都属于此状态。
- `未连接 NOT CONNECTED`：已配置适配器但没有连上。
- `真实 LIVE`：本轮只留界面和接口位置，无法启用。下单前必须二次确认。

## 4. 组件选型
| 能力 | 首选 | 说明 |
|---|---|---|
| 图表 | **TradingView Lightweight Charts**（Apache-2.0） | 成熟、轻量、主题可定制。绘图层自己实现为覆盖层插件（primitives）。Vela 作为备选评估，统一放在 `ChartEngine` 接口后面，以便替换 |
| Pine 运行 | **PineTS** | 用于运行指标和策略的子集。实施前先核对许可证和覆盖范围。不支持的语法显示清晰的诊断信息，不自研解释器 |

| 状态管理 | zustand | 按领域拆分 store |
| 动效 | motion | 面板过渡、数值跳动、主题切换 |
| 图标 | lucide-react | |
| 回测 | 自写一个轻量的浏览器端事件驱动回测器，跑在 Worker 中 | 统一接收 PineTS 的信号和积木策略的信号，后续可以替换为远程引擎 |

## 5. 旧仓库的评估与复用
| 旧仓库能力 | 处理方式 |
|---|---|
| 策略定义（StrategySpec） | 参考字段设计。新建自己的 `StrategyDefinition` 类型，不受兼容约束 |
| Pine 导出 | 参考映射规则，在前端重写积木到 Pine 的生成器 |
| 回测与报告 | 参考报告指标和结构。引擎用浏览器端的新实现，接口保留远程引擎（如 NautilusTrader）的接入位 |
| 数据适配 | 参考适配器的抽象方式。本轮只实现演示数据适配器 |
| 模拟交易控制 | 参考生命周期设计（启动、暂停、停止）。本轮只做本地模拟 |
| oc CLI / Agent 接口 | 参考命令语义，重新设计成开放的接口规范 |
| 旧 Dashboard | 不复用 |

## 6. 扩展基座（AI-native：面向外部 Agent）
- 前端内部建立统一的 **Command / Action 注册表**，所有操作都是有类型的命令，比如 `chart.setSymbol`、`indicator.add`、`backtest.run`、`paper.placeOrder`。界面、快捷键、命令面板（⌘K）和外部接口都调用这同一套命令。
- 可替换模块有固定接口：`DataAdapter`、`ChartEngine`、`ScriptRuntime`、`BacktestEngine` 和 `BrokerAdapter`（分模拟和真实两类）。
- 插件清单（manifest）包括 id、权限，以及它贡献的命令、指标、面板和适配器。本轮内置 2–3 个示例插件，验证扩展机制确实能用。
- 集成中心页面展示真实的命令 schema（自动从注册表生成）、MCP 工具映射、CLI 示例、REST/WS 接口草案和权限。连接状态统一标为“未连接”。
- 应用状态可以导出为结构化 JSON，方便 Agent 理解当前上下文。

## 7. 本轮的实现深度
- **真实可用**：工作区布局、联动、图表、指标、绘图、Pine 编辑与运行（PineTS 子集）、积木生成 Pine、浏览器端回测、本地模拟交易、命令注册表、⌘K 命令面板、主题切换。
- **演示即可**：行情（基于固定种子生成的一致示例数据，包括约 12 个标的和多个周期）、盘口、插件目录、MCP/CLI/API 的连接（展示文档和 schema，不起服务）。
- **仅预留**：真实券商、真实数据源、远程回测、账户体系。

## 8. 品牌与视觉
- 原创 logo：几何化的“O + 节点连线”，寓意组合与开放。另做字标 “Open Composer” 和 favicon，以 SVG 形式放在 `src/brand/`，可以复用，并支持单色、浅色和深色变体。
- 浅色和深色主题都完整设计，用 CSS 变量做 token。保持高信息密度，正文使用等宽数字。
- 视觉探索：顶栏和浮层用液体玻璃效果（backdrop + 轻微折射）；启动页和空状态用轻量 WebGL/Canvas shader 做背景；面板切换和数值变化用流畅动效。图表区域本身保持干净、不受干扰。具体的配色和字体在实施时自由确定。

## 9. 实施顺序
1. 品牌、主题 token、应用外壳和状态徽标
2. 示例数据和命令注册表
3. 工作区、图表、联动、自选
4. 指标与绘图
5. Pine 编辑器、PineTS 运行、上图
6. 积木构建器，生成 Pine
7. 回测和报告
8. 模拟交易
9. 集成中心和示例插件
10. 动效、shader 和细节打磨

## 10. 验证
- 走通完整闭环：选标的 → 加指标 → 写或生成策略 → 回测 → 部署到模拟 → 下单 → 查看持仓。
- 浅色和深色两套主题逐页检查；检查 LIVE 状态是否无法误触；通过命令注册表执行操作，结果应与界面操作一致；最后跑一次 `pnpm build`。
