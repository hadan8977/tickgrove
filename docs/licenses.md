# Source and dependency licensing boundary

The newly added Rust service, standalone SDKs, process plugins and Composer engine are offered under AGPL-3.0-or-later (full text in `server/COPYING`). The existing frontend has no original root license grant; this addition does not relicense it. Original author authorization is required before describing the entire combined repository as a fully licensed open-source release. Local implementation and source review can proceed; licensing clearance remains a publication blocker.

PineTS 0.11.1 is AGPL-3.0-only. Preserve its package license and provide corresponding source for distribution/network service. Public Pine fixtures retain Apache-2.0 LICENSE/NOTICE and provenance. Existing React/CodeMirror/Dockview/Vite/Zustand dependencies retain their upstream package licenses. Lightweight Charts attribution must be preserved. This document does not assert an exhaustive transitive dependency audit; exact Rust and Node dependencies are recorded by lockfiles.

No original research evidence, upstream test corpus notices or previous author grants are replaced by this service license.
